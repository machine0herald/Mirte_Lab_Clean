class mirte_lc_moveit_cpp::MirteLCMoveItActionServer : public rclcpp::Node

Implements a MoveIt-based action server for robot and gripper motion.

The node exposes the /move_to_position action and handles named targets, pose goals, and gripper commands for the MIRTE arm and gripper groups.
