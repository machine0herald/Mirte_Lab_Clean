mirte_lc_nav2.navigator_types module

class mirte_lc_nav2.navigator_types.SystematicNavigator(node=None, resolution=0.1, lethal_threshold=20.0)

Bases: BasicNavigator

Base class for systematic coverage path planners.

This class provides shared functionality for: - Occupancy map preprocessing - Contour extraction - Coordinate conversion - ROS visualization publishing - Debug visualization

Child classes should implement their own generate_path() method to produce coverage trajectories.
